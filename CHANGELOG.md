### Added

- Initial public release of the Enterprise Design System (React)
- Token-driven React 18+ / 19 component library with light + dark themes
- `ThemeProvider` / `useTheme`, `ToastProvider` / `useToast` / `showToast`
- Storybook 8 with Controls, Docs, a11y, themes, and interactions
- Jest + Testing Library coverage
- Full component set with feature parity vs `@poluru-labs/enterprise-design-system-wc`
