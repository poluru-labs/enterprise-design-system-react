## Contribution notes

This repository is structured as an industry-standard React design system:

- Component-colocation (`Component.tsx` + styles + stories + tests)
- Token layer separate from components
- Storybook as the living style guide
- Typed public entry via `src/index.ts`

See also [CONTRIBUTING.md](https://github.com/poluru-labs/enterprise-design-system-react/blob/main/CONTRIBUTING.md), [SUPPORT.md](https://github.com/poluru-labs/enterprise-design-system-react/blob/main/SUPPORT.md), and [LICENSE](https://github.com/poluru-labs/enterprise-design-system-react/blob/main/LICENSE).
