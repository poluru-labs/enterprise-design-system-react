# Support

Thanks for using `@poluru-labs/enterprise-design-system-react`.

## How to get help

| Need | Where |
| --- | --- |
| Bug report | [GitHub Issues](https://github.com/poluru-labs/enterprise-design-system-react/issues) |
| Feature request | [GitHub Issues](https://github.com/poluru-labs/enterprise-design-system-react/issues) |
| Security vulnerability | See [SECURITY.md](./SECURITY.md) — do **not** open a public issue |
| Docs / usage questions | GitHub Issues (label `question`) or email below |

## Before opening an issue

Please include:

- Package version (`@poluru-labs/enterprise-design-system-react`)
- React version
- Browser and Node.js versions
- Minimal reproduction (JSX snippet or Storybook steps)
- Expected vs actual behavior
